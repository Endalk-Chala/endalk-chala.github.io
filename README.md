# Endalkachew H. Chala — Academic Website

This repository powers my academic website: [https://endalk-chala.github.io/](https://endalk-chala.github.io/).

The site presents my research, publications, teaching, journalism and public writing, and public-facing scholarly resources.

## Site sections

- **Research** — current and developing research programs
- **Publications** — selected and full scholarly record
- **Teaching** — teaching areas, experience, and approach
- **Journalism & Public Writing** — selected public-facing work
- **Resource Library** — research resources for media and communication scholars
- **Journal Navigator** — curated communication and media journals
- **Field Opportunities** — calls, fellowships, conferences, and other opportunities
- **CV** — academic curriculum vitae

## Research profile

My work examines digital platforms, journalism, and public communication across multilingual, intercultural, and transnational contexts. Current areas include platform governance, AI-assisted content moderation, Trust & Safety, internet shutdowns and digital sovereignty, journalist safety, diaspora and transnational media, immigrant information environments, nonprofit and institutional communication, and emerging work on AI translation and language access.

## Technical notes

The site is built with Jekyll and GitHub Pages using a customized Academic Pages / Minimal Mistakes foundation.

### Local development

```bash
bundle install
bundle exec jekyll serve
```

The live site is deployed from this repository through GitHub Pages.
